# Fork Notice

This repository is a **personal, noncommercial, experimental fork** of
[God's Eye View](https://github.com/bilawalsidhu/gods-eye-view), originally
created by Bilawal Sidhu / Halfpixel, at upstream version 0.1.1.

All original attribution and licensing from the upstream project remain
intact and unmodified — see `LICENSE`, `README.md`, `DATA_SOURCES.md`, and
`SECURITY.md` for the upstream project's own terms and credits.

## Purpose

This fork exists for:

- Personal learning and experimentation
- Personal customization of the runtime for individual use
- Remote personal hosting, so the app does not depend on a local machine
  being on
- Eventual deployment to Google Cloud Run under a personal custom domain

## Not the upstream project

This fork is not affiliated with, endorsed by, or presenting itself as the

work intended for noncommercial use. The upstream application code is

## Third-party data and licensing

All public and third-party data sources integrated by this application
(mapping, aviation, maritime, satellite, weather, CCTV, and other feeds)
retain their own individual provider licensing, terms of service, and
attribution requirements, as documented in `DATA_SOURCES.md`. Using this
fork does not change or waive any of those upstream terms — in particular,
the bundled TeleGeography submarine cable dataset remains

own attribution or non-commercial restrictions that must be preserved.
